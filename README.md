# SmartBudgetManager
A project for managing Budget.
README — SmartBudget Manager
1. Overview
SmartBudget Manager is an Excel-based budgeting tool that helps users record their income and expenses, monitor their financial balance, and track spending by category.
2. Main Features
Record income and expense transactions.
Organize expenses into predefined categories.
Calculate total income, total expenses, and balance automatically.
Display budget information by category.
Visualize expenses using a pie chart.
Identify budget overruns through visual warnings.
3. Requirements
Microsoft Excel 2016, 2019, 2021, Microsoft 365, or an equivalent compatible spreadsheet application.
The SmartBudget_Manager.xlsx workbook.

4. Getting Started
Open SmartBudget_Manager.xlsx in a compatible spreadsheet application.
Select the Transactions worksheet.
Enter transaction dates and descriptions.
Select the transaction type and relevant category.
Enter the amount in the appropriate Income or Expense column.
Open the Dashboard worksheet to review the financial summary and chart.
